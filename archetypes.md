# Index — pick one, then read that system file

Do not design from this table. After you pick an id, read `systems/<id>.md` in full.

| id | kind | energy | pick when | never when |
|---|---|---|---|---|
| `ritual-object` | consumer habit / clip / journal / weekly return | restrained | The product is a tray, box, shelf, or Sunday ritual. User drops things in and comes back. | Infra, developer tools, agency sites |
| `product-stage-night` | developer / pro tool | quiet | Technical buyers. The product UI is the proof. Night. | Consumer habit, portfolios, stories without a UI |
| `product-stage-day` | friendly pro tool | restrained | Same, but daylight and warmer. Still a working UI in the hero. | Clipping/journal rituals (use `ritual-object`) |
| `one-world` | brand / studio / campaign | hard | First minute can be one world and one sentence. | Anything that must convert in one glance with a form |
| `type-bleed` | agency | hard | The name or sentence is the architecture. | Apps, docs, commerce |
| `work-sequence` | agency portfolio | hard | Client work, large, sequential. | Personal sites, SaaS |
| `person-essay` | personal | restrained | The person is the IA. Words are controls. | Studios, products |
| `empty-field` | personal | quiet | Almost nothing on the first screen. | Marketing |
| `object-letter` | hardware / object story | restrained | Sold with a letter and a few true pictures. | Feature-grid SaaS |
| `editorial-essay` | long read | restrained | The page is for reading. | Seat-selling landings |
| `recent-overflow` | any | inferred | Nothing above fits. Open recent.design, one piece only. | When a row above already fits |

## 拾贝-class briefs

Weekly return, inbox, 摘录, 稍后再看, read-it-later, bookmark tray, Sunday digest → **`ritual-object`**.  
Not `product-stage-day`. Day-stage turns them into centered SaaS.
