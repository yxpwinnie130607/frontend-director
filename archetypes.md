# Archetypes — pick one, execute that one

This is the working library. **Fourteen directions. Not a hundred templates.**

A template here is a *system*: one thesis, one hard layer, one energy. It is not an HTML file to clone. After you pick, steal structure and courage. Leave the skin.

## Match

1. From the design read, take `page kind` + `energy` + `hard layer`.
2. Score the table. Keep rows whose **kind** matches. Prefer the row whose **energy** and **layer** match.
3. Pick **exactly one** `id`. Say it out loud: `Executing <id> because <one reason>.`
4. Read that card below. Do not read the others.
5. Execute that system for the whole page. Do not blend two ids. Do not average Linear with Offer Studio.
6. If nothing fits: open https://recent.design, filter to the same kind, pick **one** live piece, write a six-line card in the same shape as below, then execute that. Do not keep grazing.

Energy:

- `quiet` — almost no stunt. Space and type do the work.
- `restrained` — one layer, visible but not cinematic.
- `hard` — that one layer goes to the wall. Everything else whispers.

## Cards

Read only the card you picked.

### product-hero-quiet — https://linear.app

Night, thin chrome, a **real product** under a short specific headline. Type is large but secondary. Motion lives inside the product, not around it. No orb, no fake 3D, no "watch a poster of the app."

Execute: first viewport = headline + the actual UI (or an honest miniature). One accent at most. The page still works with motion off.

### product-hero-warm — https://amie.so

Same structure as quiet, daylight instead of night. One friendly accent. Headline names a job, not a vibe. Product still sits in the hero.

Execute: light ground, one pill accent, operational subcopy, real UI. Do not add a second colour story.

### brand-one-world — https://offerstudio.group

One sentence + one world for a full first minute. Then a door into a quieter work stage. Theme flip is a chapter change, not a random invert.

Execute: first viewport contains only the thesis. No eyebrow, no card, no second climax on the same screen. After the door, chrome goes thin.

### type-as-building — https://andagain.uk

The wordmark is cropped by the viewport. A hairline. Small meta. A short manifesto. No hero image.

Execute: type is the only object in the first screen. Black/white or one material. Lists later, never icon grids.

### work-sequence — https://locomotive.ca

Work is the page. Featured projects in a sequence, large, named, uneven. The studio is a caption.

Execute: big captures, not six equal tiles. Client names can be quiet. No capabilities-as-icons.

### unusual-studio — https://www.therawmaterials.com

A studio that refuses the default agency kit. Sections behave like chapters of a stance ("when everything is the same, being different is the opportunity"), not like a service menu.

Execute: one structural stunt for the whole site. Copy is a point of view. Do not add a second stunt.

### person-as-ia — https://ped.ro

The bio is the IA. Words are controls. No project grid competing with the person. Depth via focus, not borders.

Execute: the person is the page. Expand-in-place beats a portfolio index. Voice must be theirs, not "Yo I'm [Name]" copied.

### empty-island — https://kons.fyi

A field and one small object. Willing to look unfinished to people who want a grid.

Execute: almost nothing in the first viewport. One toy or one island. Proof comes after, if at all.

### one-metaphor — https://imjane.top

One personal object (a tree, not *the* tree) is the entire entrance. UI is a whisper.

Execute: invent *their* object. If you cannot name why this object is this person, this id is wrong — pick `person-as-ia` or `empty-island` instead.

### object-letter — https://opalcamera.com

A hardware / object company that writes a letter. The product is in the prose and in a few true pictures, not in a spec table.

Execute: one column of specific sentences. Few images, large. No beige-brass craft kit. No row-per-spec sheet.

### editorial-essay — https://thenewindustrials.com

A designed essay. Measure, crop, pull quotes. The page is for reading.

Execute: reading rhythm over cards. No bento, no pill nav pretending to be a magazine.

### community-poster — Recent filter: Websites + the stance of a joinable poster

A school, community, or event should feel like a poster you can walk into, not a course catalog.

Execute: large type, one date or one promise, a single join action. Do not emit three identical course cards.

### recent-overflow

Only if the table missed. Open https://recent.design, filter to the brief's kind (Websites / Interfaces / Branding / Motion / Illustration / Posters / Print). Pick one piece. Write:

```
id: recent-<slug>
kind / energy / layer:
use when:
omit:
execute:
do not clone:
```

Then execute that. One piece. Stop browsing.
