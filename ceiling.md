# Ceiling — why the reference sites work

Optional. Read after a technique is loaded. Not a picker. Not a 2D taste kit.

The living ceiling is **Recent**: https://recent.design. The homepage masonry (earth, paper, glass, ice) **is** the visual template for studio objects: one complete thing, physical light, empty field. The Web filter adds motion (portal rooms, shader dissolve, spatial decks). Use both. Do not flatten them into a form.

## How to use Recent

Canonical URL: https://recent.design  
Old URL that still works: https://godly.website

When you need a fresh ceiling:

1. Filter **Web**. Open website posts, not 3D stills, posters, or illustration.
2. For each, write the loop: pointer / scroll / type / drag. Write the air. Write the scene change.
3. Steal the loop. Leave the skin (no torus, no flower, no Mac wallpaper, no Earth map, no jacket).
4. If the first viewport of your page cannot be used the way that Recent site can, rebuild.
5. If you are making a studio object, match Earth / Crumple composition: whole object, FOV ~32, `z` ~5.2–6.2, HUD off the mesh.

## Steal courage, not a 2D recipe

These are useful *after* you already have a WebGL first viewport. They are **not** the first screen:

- Displace (https://displace.agency) — the homepage is usable. Do not steal the Mac skin (素笺).
- Offer Studio (https://offerstudio.group) — one sentence and a world. Do not steal the burst kit.
- Linear / Amie / Interfere — specific sentences, thin chrome. **2D product marketing. Not this skill's first viewport.**
- ped.ro / kons.fyi / AndAgain — type and emptiness. Do not crop a huge word onto a SaaS page.

If a post on Recent is polished 2D (Interfere), it is featured, not the bar.
