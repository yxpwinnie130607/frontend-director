# Ceiling — sites that already did it

These were read on the live web, not from memory of "premium SaaS." Steal courage and structure. Do not clone skins. This file is optional reading after a technique is loaded. It is **not a picker**.

The living ceiling is **Godly, now Recent**: https://recent.design. The homepage masonry (earth, paper, glass, ice) **is** the visual template for studio objects: one complete thing, physical light, empty field. The Web filter adds motion (portal rooms, shader dissolve, spatial decks). Use both. Do not flatten them into a form.

---

## Displace — https://displace.agency  (Recent: Websites, Interactive)

**Kind:** agency site that is a machine.

**What to steal:** the homepage *is* usable. You open, type, drag.

**Do not steal:** the Mac skin, the traffic lights, the wallpaper. A fake Mac window of gray bars is 素笺 and it failed.

## How to use Godly / Recent

Canonical URL: https://recent.design  
Old URL that still works: https://godly.website

When you need a fresh ceiling:

1. Filter **Web**. Open website posts, not 3D stills, posters, or illustration.
2. For each, write the loop: pointer / scroll / type / drag.
3. Steal the loop. Leave the skin (no torus, no flower, no Mac wallpaper).
4. If the first viewport of your page cannot be used the way that Recent site can, rebuild.
5. If you are making a studio object, match Earth / Crumple composition: whole object, air, HUD off the mesh.
